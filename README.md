# MAI5100: Fundamentals of Artificial Intelligence @ UG

Graduate-level introduction to AI: intelligent agents, search, constraint satisfaction, adversarial search, decision making under uncertainty, reinforcement learning, probabilistic reasoning, and machine learning.

| **Info** | **Details** |
|---|---|
| **Course Code** | MAI5100 |
| **Iteration** | 2 (2026/2027) |
| **Modality** | Online (Zoom) |
| **Live sessions** | Saturdays, 9:00 AM - 1:00 PM Guyana time (UTC-4) |
| **Dates** | Sat 24-Oct-2026 to Sat 20-Feb-2027 (15 sessions; no class Nov 7, Dec 26, Jan 2) |
| **Course Instructor** | [Dr. Christopher Clarke](https://csclarke.com/) |
| **Pre-requisites** | Basic to intermediate math, Python programming |
| **Textbook** | *Artificial Intelligence: A Modern Approach* (4th ed.), Russell & Norvig |
